# Sprint_5

Финальный проект спринта 5 — UI-автотесты для учебного сервиса «Доска».

## Описание

Проект содержит автоматизированные UI-тесты на Python (Selenium + pytest) для сервиса объявлений «Доска».  
Покрыты следующие сценарии:

- Регистрация пользователя (успешная, с невалидным email, с существующим пользователем)
- Авторизация (логин)
- Выход из аккаунта (логаут)
- Создание объявления (неавторизованным и авторизованным пользователем)

## Структура проекта

```
Sprint_5/
├── locators.py            # Локаторы элементов
├── helpers.py             # Вспомогательные функции
├── tests/
│   ├── conftest.py        # Фикстуры pytest
│   ├── test_registration.py  # Тесты регистрации
│   ├── test_login.py         # Тесты авторизации
│   ├── test_logout.py        # Тесты выхода
│   └── test_create_ad.py     # Тесты создания объявления
├── README.md
├── .gitignore
└── requirements.txt
```

## Запуск тестов

1. Установить зависимости:
```bash
pip install -r requirements.txt
```

2. Запустить все тесты:
```bash
pytest tests/
```

## Требования

- Python 3.13
- Google Chrome
- Selenium 4.32.0
- pytest
